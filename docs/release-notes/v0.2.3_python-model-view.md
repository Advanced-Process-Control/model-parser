# v0.2.3 - Python model view

## Highlights

- Add `model-parser emit python MODEL.ir.json -o model.py`.
- Generate a SciPy-shaped ODE RHS, `f_<model>(t, state, parameters[, inputs])`.
- Generate `outputs_<model>` when the IR contains output equations.
- Keep generated modules dependency-free and deterministic.

## Compatibility

This release is additive. The canonical IR schema and existing Julia targets
are unchanged.
